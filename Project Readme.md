## 📊 Dataset Information
* **Dataset Name:** Customer & Sales Analytics Dataset
* **Source:** IBM SkillsBuild / Standard Analytical Dataset
* **Key Features:**
  * `CustomerID`: Unique identifier for each record
  * `Age`: Customer demographic information
  * `Annual_Income_k$`: Income metrics in thousands of dollars
  * `Spending_Score`: Normalized score based on purchasing behavior
